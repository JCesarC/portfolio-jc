## Context

Chiplo helps real-estate agents and brokers originate mortgages. Before a file reaches a lender, an advisor has to estimate whether the applicant can afford the payment. Done by hand, that meant reading through the applicant's bank statements, asking about their income and running the numbers: an hour or more per applicant.

## What I built

A pipeline that reads the applicant's uploaded bank statements and produces a payment-capacity estimate with a written justification an advisor can check:

- **Income categorization.** GPT-4 categorizes the income found in each uploaded statement.
- **Credit policy by employment type.** Different rules apply depending on how the applicant earns their income.
- **Anomaly exclusion.** Anomalous deposits are excluded so they do not inflate the estimate.
- **Explainability.** Every estimate ships with a reasoning summary in the Next.js app, so advisors can see _why_ and override when needed.

## Key decisions

- **Automate the advisors' criteria, not new ones.** The policies the pipeline applies, from how income is reviewed to how payment capacity is calculated, are the same ones advisors used in their manual reviews. The result can be checked against what an advisor would have done by hand.
- **Every figure comes from the applicant's own statements.** The estimate is built only from the uploaded bank statements, and anomalous deposits are excluded so a one-off deposit cannot inflate it.
- **A number alone is not enough.** Each assessment ships with the reasoning behind it, shown in the Next.js app, so the advisor can see how the figure was reached before relying on it.

## Results

- **From an hour or more to minutes.** With the pipeline, a review that took an advisor an hour or more produced an estimate, with its reasoning, in minutes. This was not formally measured at the time; it is my estimate of the before and after.
- **Built into every applicant file.** The assessment ran on every applicant file in Chiplo, so advisors saw the applicant's payment capacity and its reasoning with no manual step.
