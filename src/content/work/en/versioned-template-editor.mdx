## Context

Each lender has its own mortgage application forms, and they change. Mapping application data into those forms was manual work that could take up to a full day per change.

## What I built

A template editor where the team remaps data fields on a form and publishes the new version themselves:

<Flow
  steps={[
    'Upload lender form',
    'Map data fields',
    'Publish new version',
    'Documents auto-filled',
    'Roll back if needed',
  ]}
/>

- **Versioning by default.** Every publish creates a new immutable version, so any earlier version can be restored safely.
- **Self-service publishing.** The team remaps fields and publishes from the editor (React, Node.js, MongoDB, S3).
