## Context

A mortgage file is a bundle of filled forms, IDs, statements and signed documents. Advisors need to download the complete, lender-ready package, and those files contain sensitive financial data.

## What I built

A set of Lambda functions that each do one job, chained into a pipeline:

<Flow steps={['Auto-fill forms', 'Compress PDFs', 'Merge documents', 'Package ZIP', 'Pre-signed S3 URL']} />

- **Auto-fill** of mortgage forms with the applicant’s data.
- **Compression** reduces PDF size by up to 40%.
- **Secure delivery** through short-lived pre-signed S3 URLs; nothing is exposed publicly.
